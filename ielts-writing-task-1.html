WRITING TASK 1

Describe the important features, not every number

Build a clear Task 1 response by identifying the overall picture, selecting meaningful comparisons and supporting them with data.

Start with the overall picture

Before writing details, decide what the visual information is mainly showing. Look for increases, decreases, stability, large differences, similarities, stages or changes over time. Your overview should communicate the major features without becoming a list of numbers.

A useful structure

Introduction: paraphrase what the visual shows. Overview: summarize the two or three most important features. Details: organize relevant figures into logical groups and make comparisons.

Choose comparisons carefully

If a chart contains several categories, you do not need to describe every value. Group similar trends and compare the highest, lowest, largest change or notable contrast. Use exact figures to support the important points.

Language for change

Useful verbs include rise, increase, grow, climb, fall, decline, drop, remain stable and fluctuate. Nouns include an increase, a rise, a decline, a drop and a fluctuation. Check which grammatical structure follows each word.

Comparing data

Useful patterns include “X was considerably higher than Y,” “X increased by approximately…,” and “By the end of the period, X had overtaken Y.” Avoid repeating one comparison structure throughout the report.

Process and map tasks

For a process, focus on sequence and transformation rather than numerical comparison. For a map, identify major changes such as new buildings, relocated facilities, removed features and changes in access. Group related changes so the report is easy to follow.

Common mistakes

  • No clear overview.
  • Listing every number without comparison.
  • Giving opinions about why a trend happened when the visual does not provide a reason.
  • Using “increase” and “decrease” with incorrect grammar.
  • Writing a conclusion that simply repeats the overview.

Practice task

Imagine a chart comparing the percentage of commuters using cars, buses and bicycles in three years. Before writing, identify the largest category in each year, the biggest change and any category that remained relatively stable. Those observations should drive your report.
